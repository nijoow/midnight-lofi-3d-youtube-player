## 로컬 복원

```sh
git clone --branch recovery/production-2026-10-22 https://github.com/nijoow/midnight-lofi-3d-youtube-player.git
cd midnight-lofi-3d-youtube-player
node .yarn/releases/yarn-4.3.1.cjs install --immutable
cp .env.example .env.local
# .env.local의 YOUTUBE_API_KEY에 유효한 키를 설정한다.
node .yarn/releases/yarn-4.3.1.cjs dev
```

Node.js 24와 저장소에 포함된 Yarn 4.3.1을 사용한다. API 키의 실제 값, 로컬 환경변수 파일, `node_modules`, `.next` 등 생성 파일은 백업에 포함하지 않는다. `YOUTUBE_API_KEY`는 기존 Vercel 프로젝트의 환경변수로 별도 관리되고 있다.

## 파일 일치 확인

저장소 루트에서 다음 명령을 실행한다.

```sh
python - <<'PY'
import hashlib
import json
from pathlib import Path

files = json.loads(Path('docs/recovery/production-2026-10-22.json').read_text())
snapshot = hashlib.sha256(json.dumps(files, sort_keys=True).encode()).hexdigest()
assert snapshot == '1fc4f1d38afb402f024e6be24004e6183eee14b2da7c6becbbfe9b519738816e'
for entry in files:
    data = Path(entry['file']).read_bytes()
    assert len(data) == entry['size'], entry['file']
    assert hashlib.sha1(data).hexdigest() == entry['sha'], entry['file']
print(f'운영 소스 {len(files)}개 일치')
PY
```
